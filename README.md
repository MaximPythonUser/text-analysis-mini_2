text-analysis-mini

Мини-набор функций для базового анализа текста на Python. Текущая функция count_vowels() — простой пример подсчёта характеристик строки. Может быть основой для валидации названий товаров, анализа длины и состава текста в карточках, подсчёта слогов и других задач, где нужно разбирать строку посимвольно.
